# Complaint-O-Tron 3000
  A complaint management application with AI-powered insights, built using Python and tkinter.
## Features

* User registration and login.
* Submit and view complaints.
* Moderator dashboard to manage complaints.
* AI insights including urgency prediction, sentiment analysis, and more.

## Prerequisites

* Python 3.9 or higher
* Required libraries (see requirements.txt)

## Installation

* Clone the repository:git clone https://github.com/your-username/Complaint-O-Tron-3000.git
* cd Complaint-O-Tron-3000

* Create a virtual environment (optional but recommended):python -m venv .venv
.\.venv\Scripts\Activate.ps1  # On Windows

**OR**

source .venv/bin/activate  # On macOS/Linux

* Install dependencies:pip install -r requirements.txt


* Run the application:python main.py
